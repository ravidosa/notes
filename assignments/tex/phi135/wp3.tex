\problem
\subproblem{(a)}
\begin{equation*}
\begin{nd}[rules=lukasiewicz,justformat=just]
\hypo {1} {p \Rightarrow q}
\open
\hypo {2} {p \land r}
\have {3} {p} \ae{2}
\have {4} {q} \ie{1,3}
\close
\have {5} {(p \land r) \Rightarrow q} \ii{2-4}
\end{nd}
\end{equation*}
We then see that $p \Rightarrow q \vdash (p \land r) \Rightarrow q$ is a valid argument in Łukasiewicz logic.

\subproblem{(b)}
Let $p = 1$, and $q = i$. We see that $\lnot q = i$, so $\lnot q \Rightarrow q = 1$. However, $p \Rightarrow q = i$. Consequently, the argument $\lnot q \Rightarrow q \vdash p \Rightarrow q$ is an invalid argument in Łukasiewicz logic.
